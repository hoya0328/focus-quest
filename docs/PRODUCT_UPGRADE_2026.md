# Focus Quest 제품 고도화 검증안

## 이번 고도화의 목표

Focus Quest를 단순히 귀여운 타이머가 아니라, **시작하기 어렵고 집중이 자주 끊기는 사람이 한 번의 모험을 끝까지 완주하도록 돕는 제품**으로 정리한다.

이번 작업에서 제품의 핵심 가치를 세 가지로 좁혔다.

1. 첫 화면에서 할 일과 시간을 빠르게 정하고 바로 시작한다.
2. 집중 중 떠오른 딴생각을 잠시 보관해 흐름을 지킨다.
3. 완료 기록과 연속 집중일을 통해 다음 세션을 시작할 이유를 만든다.

## 구현된 제품 개선

- 첫 사용자는 `한 가지 적기 → 시간 고르기 → 장면과 함께 완주` 순서를 바로 확인한다.
- 재방문 사용자는 지난 목표·시간·모험을 첫 화면에서 한 번에 다시 시작한다.
- 완주 기록을 바탕으로 익숙한 집중 시간을 빠른 시작에 추천한다.
- 집중 중 떠오른 생각을 화면을 떠나지 않고 보관하고, 완료 뒤 다시 확인한다.
- 연속 집중일과 주간 완주 기록으로 다음 세션의 동기를 제공한다.
- Phaser 모험 장면과 PDF 퀘스트 보드는 필요할 때만 내려받도록 초기 번들에서 분리했다.

## 결제 가설

가격과 유료 범위는 아직 검증되지 않은 가설이다.

- 무료: 기본 타이머, 세 가지 모험, 최근 기록, 로컬 딴생각 보관
- Pro 후보: 기기 간 전체 기록 동기화, 사용자별 루틴, 고급 집중 분석, Silent Camp 확장, 추가 모험과 꾸미기
- 가격 실험 후보: 월 4,900원 또는 연 39,000원

유료화를 시작하기 전에 최소 10명의 실제 베타 사용자에게 다음을 확인한다.

1. 첫 집중을 설명 없이 시작할 수 있는가.
2. 7일 안에 세 번 이상 다시 사용하는가.
3. 딴생각 보관이나 추천 시간이 실제 완주율을 높이는가.
4. 어떤 기능을 잃으면 아쉬워서 결제를 고려하는가.
5. 결제 화면에서 실제로 선택하는 가격대는 무엇인가.

## 성공 지표

- 방문 후 첫 세션 시작률
- 시작한 집중 세션의 완주율
- 7일 내 재방문율과 3회 이상 집중 사용자 비율
- 딴생각 보관 사용자의 세션 완주율 변화
- 추천 시간 선택률
- 무료 체험 후 결제 의향과 실제 결제 전환율

## 다음 제품 우선순위

1. 실제 사용자 10명 비공개 베타와 행동 로그 측정
2. 첫 실행 안내와 빈 상태 개선
3. 목표별 루틴 저장 및 다음 세션 원클릭 재시작
4. 접근 가능한 알림·PIP·모바일 백그라운드 동작 검증
5. Pro 기능 하나만 선택한 결제 의향 실험

가상 사용자 열 명은 제품 판단을 빠르게 하기 위한 도구일 뿐, 실제 고객 검증을 대신하지 않는다.
