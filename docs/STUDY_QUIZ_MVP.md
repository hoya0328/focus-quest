# Focus Quest — 집중 체크포인트 퀴즈 MVP

업데이트: 2026-11-12

## 제품 방향

Focus Quest는 PDF를 대신 요약하는 서비스가 아니라, 사용자가 실제로 공부한 범위를 짧게 회상하도록 돕는 뽀모도로 타이머다.

## 사용자 흐름

1. 로그인한 사용자가 과목에 텍스트형 PDF를 올린다.
2. 브라우저가 페이지별 텍스트를 추출하고 원본과 퀴즈용 페이지 인덱스를 비공개 계정 저장소에 보관한다.
3. 사용자는 퀘스트에 PDF와 오늘의 목표 페이지를 연결한다.
4. 집중이 끝나면 실제 도달 페이지를 입력한다.
5. 해당 범위의 원문을 바탕으로 객관식 빈칸 문제 한 개를 푼다.
6. 휴식이 끝나면 같은 범위의 다른 문제 한 개로 다시 회상한다.
7. 퀴즈를 만들 수 없거나 사용자가 원하면 확인 단계를 건너뛸 수 있다.

## 비용과 개인정보

- 초기 MVP는 생성형 AI API를 호출하지 않는다.
- PDF 원본은 기존 Supabase 비공개 Storage와 사용자별 RLS를 유지한다.
- 페이지 텍스트는 최대 15만 자만 저장하며, 퀴즈는 공부한 페이지 범위 안에서만 생성한다.
- 정답을 맞혀야 휴식할 수 있도록 강제하지 않는다.

## 기존 기능에서 제거한 것

- PDF 전체 요약
- 과목 성격 자동 분석
- 3~7개 퀘스트 자동 생성
- 예상 학습 시간과 추천 공부법 생성
- OpenAI `/api/analyze-pdf` 호출

기존 분석 자료는 삭제하지 않지만 새 퀴즈 인덱스가 없으므로 다시 업로드해야 체크포인트 퀴즈에 사용할 수 있다.

- 반복 사용과 결제 의향이 확인된 뒤에만 AI 문제 개선 옵션 검토
