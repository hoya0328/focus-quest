# Focus Quest 제품 로드맵

현재 기술 계약은 [기술 인수인계](engineering/README.md), 미확인 항목은 [LIMITATIONS](engineering/LIMITATIONS.md)를 따른다. 과거 실행 근거는 날짜별 문서와 구분한다.

## 현재 제품 범위

현재 MVP는 웹·PWA이며 대표 주소는 https://focus-quest.hoya0328.workers.dev 이다.
기존 ChatGPT Site는 과거 배포 주소로 남겨 두며 최신 릴리스 주소로 안내하지 않는다.
`.openai/hosting.json`의 프로젝트 ID는 호환성과 이력 보존을 위해 변경하지 않는다.

### 구현 완료

- 게스트 시작, 이메일 계정, 계정별 저장·기록 병합과 다기기 세션 복구
- 동료 선택 직후 25분 집중·5분 휴식, 모바일 전용 미리보기와 기존 맞춤 준비실
- 세 동료의 집중·완료·휴식 Phaser 장면, 사용자 지정 시간, 여러 세트 원정
- 작은 타이머, 앱 내 종료 알림, PWA 설치와 선택형 Web Push의 코드 경로
- 10·25·50·100회 월드 성장, 첫 세 번의 흔적, 누적 시간 기반 동료 외형, 이후 원정 유물·숙련·계절 사건
- 오늘의 목표, Camp Log, 중단 후 Recovery Quest, 최근 모험 재시작
- 과목·수동 퀘스트·비공개 PDF, 공부한 범위의 체크포인트·복귀 문제
- 외부 AI 없는 로컬 공부 가이드, 오답·자신감 기반 복습, 시험 원정·4주 리포트
- 인증된 비공개 캠프, 동시 타이머·임시 채팅, 재접속·차단·신고·다시 모이기
- 비구매 Plus 관심도 조사, 내용 없는 이벤트 집계, 백업 내보내기·무결성 검사와 신고 처리 도구

구현 완료는 실제 OS 알림 전달이나 실제 사용자의 재방문 효과가 입증됐다는 뜻이 아니다.

## 측정 경계

- 현재 서버 제품 이벤트는 로그인 사용자만 포함한다. 게스트의 행동·목표·자료를 추가 수집하지 않는다.
- 창 내 고유 로그인 사용자 비율은 전체 방문자 전환율이 아니다.
- `returned_after_7d`는 이 기기·계정에서 7일 이상 지난 복귀 신호이며 가입 코호트의 D7 유지율이 아니다.
- 2026-11-25 수정 전의 이 이벤트는 첫 방문 오집계 가능성이 있으므로 유지율 산정에 사용하지 않는다.
- 표본이 충분하지 않은 동안 0%·100%를 제품 성과로 해석하지 않는다.

## 베타 판단 기준

실제 사용자에게 설명 없이 링크를 전달하고 다음을 측정한다.

- 첫 집중을 시작하고 완주하는 데 막히는 지점
- 성장·휴식·다음 행동을 이해하는지
- 다음 날과 일주일 뒤 다시 쓰는지
- 캐릭터의 외형보다 모험의 진행이 재사용 이유인지

초기 목표치는 가설이며 달성 사실이 아니다: 첫 집중 시작 45%, 완주 65%, 24시간 재시작 30%, 가입 사용자 D7 재방문 25%.
측정 모수와 코호트가 없는 지표는 숫자를 만들어 채우지 않는다.

## 보류한 확장

- 실제 유료 결제와 유료 AI 호출·비용 한도
- 추가 지역·캐릭터·대형 꾸미기 상점
- 앱스토어용 네이티브 빌드·서명·심사
- 공개 랭킹·피드·범용 AI 채팅

현재 반복 사용 가치와 실기기 안정성을 확인하기 전에는 위 기능을 확장하지 않는다.
