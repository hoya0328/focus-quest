## 공개 베타 오픈 계획

### P0 — 오픈 전에 반드시 닫을 것

1. **기능 안내와 실제 동작 일치 — 완료**
   - 캐릭터별 10·25·50·100회 기준의 5단계 월드를 집중·휴식 Phaser 장면에 연결했다.
   - README와 앱의 캠프·AI·PDF 설명을 현재 범위에 맞췄다.
2. **스테이징과 자동 사용자 흐름 검사 — 완료**
   - GitHub Actions 안에서 매번 새로 만드는 격리 Supabase와 Playwright 실제 계정 A/B 검사를 구성했다.
   - 무료 프로젝트 한도로 별도 원격 스테이징은 만들지 않았고, 운영 데이터에서 파괴적 검사를 대신 실행하지 않는다.
   - GitHub Actions 실행 `45408536592`에서 이메일 로그인, 계정 A/B 격리, 다기기 복구, PDF 퀴즈, 계정 삭제를 모두 확인했다.
3. **캠프 공개 범위 결정 — 완료**
   - 현재 Silent Camp는 `초대 전용 베타`로 표시하고, 코드는 방 위치일 뿐 참가자 신원 확인 수단이 아님을 화면에 명시했다.
   - 정식 공개 전에는 Supabase Auth 기반 private Realtime channel 또는 서버 서명 방식으로 발신자를 검증한다.
4. **운영 관측과 피드백 — MVP 완료**
   - Cloudflare API 오류는 요청 ID·오류 코드·서비스·상태만 구조화 기록하며 사용자 목표·PDF·퀴즈 본문은 기록하지 않는다.
   - `앱 열기 → 집중 시작 → 완주 → 7일 복귀` 이벤트와 개인정보를 넣지 않는 이메일 피드백 경로를 추가했다.
   - 장애 판단·롤백·Supabase/Cloudflare 확인 절차를 `OPERATIONS_RUNBOOK.md`에 정리했다.
5. **릴리스 게이트 — 완료**
   - 린트, 타입, 로직, 운영 빌드, 렌더, 비밀정보, 의존성, 익명 경계, 성능 예산을 한 명령으로 검사한다.
   - 운영 마이그레이션 2개 적용, 익명 경계 재검사, 격리 E2E와 GitHub 반영을 완료했다. Cloudflare 배포는 별도 공개 요청 전까지 실행하지 않는다.

### 경쟁력 검증 게이트

기능을 더 추가하기 전에 Focus Quest가 `모험형 집중`으로 선택되는지 확인한다.

1. 첫 화면에서 10초 안에 `누구와 무엇을 얼마나 할지` 이해할 수 있게 한다.
2. 세 모험의 진행·완료·휴식 연출과 사운드 품질을 한 제품처럼 맞춘다.
3. **첫 3회 성장 경험 — 완료(2026-11-24):** 10분 이상 완주마다 동료별 첫 원정 흔적을 남기고, 1·2·3회 기록과 다음 월드의 실제 배경·이름·남은 횟수를 미리 보여준다. 5분 Recovery Quest는 기존 기준대로 제외한다.
4. 유령집사의 공부방과 Focus Traveller를 포함한 동일 25분 비교 테스트에서 다음 날 재선택 이유를 수집한다.
5. 5명 이상의 목표 사용자 중 3명 이상이 `캐릭터가 아니라 모험 진행 때문에 다시 썼다`고 답해야 추가 월드·진화를 개발한다.

기준을 통과하기 전에는 캐릭터 수집 확대, 공개 순위, 범용 AI 코치, 대형 꾸미기 상점을 만들지 않는다.

현재 구현 범위:

- 기존 로컬 집중 기록과 타이머 설정을 D1 클라우드 상태로 저장

- 버전 충돌 감지와 한 번의 자동 병합

현재 추가 구현:

후속 범위:

완료 조건:

- 다른 기기에서 동일 설정·완료 기록·진행 중 세션 확인

- 누적 시간보다 완료 개념과 다음 행동이 먼저 보임

### 2단계 — Retention

목표: 사용자가 4주 동안 자신의 공부 동료와 학습 경로로 돌아오게 한다.

- 자신감·오답 기반 복습 퀘스트
- 최소 3개 유효 퀘스트 이후 개인별 집중·휴식·세트 추천
- 놓친 계획을 줄여 다시 시작시키는 Recovery Quest
- 시험일까지 남은 경로와 과부하 경고
- 캐릭터가 지난 과목과 성취를 기억하는 Companion Memory
- 퀘스트 완료로 복원되는 월드와 수집 요소
- 사용자가 허용한 시간대의 부드러운 알림
- 분석·퀘스트 품질 피드백

통과 기준:

- 4주차 재방문율 목표치 달성
- 첫 주 대비 4주차 유효 퀘스트가 급감하지 않음
- 복귀 퀘스트를 받은 휴면 사용자의 재시작률 개선

### 3단계 — Revenue

목표: 학습 결과 개선에 대해 지불할 사용자를 찾는다.

- 무료 분석 한도 실험
- Plus 결제 의향 테스트
- 적응형 시험 원정과 장기 리포트
- 추가 모험 지역과 캐릭터 스토리
- AI 비용과 결제 전환을 함께 보는 단위 경제성 대시보드

결제 실험:

- 월 4,900원 / 5,900원 / 6,900원 가격 민감도 비교
- 기능 잠금 화면보다 결과 미리보기 후 업그레이드 제안
- 연간 결제는 월 결제의 반복 사용 가치를 확인한 뒤 도입

### 4단계 — Social

목표: 경쟁 스트레스 없이 함께 공부하는 이유를 만든다.

- Silent Party
- 소규모 비공개 Study Camp
- 친구의 온라인 상태 대신 `함께 집중 중` 정도만 표시
- 공유 자료의 권한과 저작권 정책
- 선택형 Mentor View

실시간 랭킹과 공개 피드는 사용자의 요구가 반복해서 확인될 때만 검토한다.
