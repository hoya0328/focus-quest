# Focus Quest 제품 로드맵

마지막 업데이트: 2026-08-11

## 현재 상태

### 완료된 기반

- 반응형 PC·모바일 PWA
- 등산·수영·낚시 캐릭터와 Phaser 기반 모험 장면
- 사용자 지정 집중·휴식 시간
- 전체 화면 집중, 일시 정지, 세션 복구
- 집중·휴식 전환과 장면 안 완료 연출
- 앰비언트 BGM
- 로컬 주간 기록과 최근 세션
- 오늘의 한 가지 입력과 10·25·45분 빠른 시작
- 집중 목표의 진행 중·완료·최근 기록 연결
- Camp Log 결과 선택과 선택별 다음 행동

### 아직 제품화되지 않은 기반

- 여러 집중·휴식 세트를 하나의 원정으로 잇는 진행 흐름
- 중단 후 부담 없이 돌아오는 Recovery Quest
- 완주가 배경과 동료의 변화로 쌓이는 장기 성장
- 실제 AI 분석의 비용 통제와 사용량 제한
- 운영 지표와 오류 관측

## 2026-08-11 — 결제 없는 타이머 고도화 제안

목표: `시작 → 완주 → 다음 행동 → 재방문`을 하나의 루프로 닫고, AI 과금 전에 반복 사용 가치를 검증한다.

### P0 — 다음 개발 묶음

1. **Camp Log Lite — 완료**
   - 완료 직후 `끝냈어요 / 조금 남았어요 / 더 작게 나눌래요` 중 하나를 선택한다.
   - 선택에 따라 휴식, 같은 목표 한 세트 추가, 5·10분 미니 퀘스트 중 하나를 바로 제안한다.
2. **여러 세트 원정**
   - `25분 집중 + 5분 휴식 × 3세트`처럼 시작 전에 전체 경로를 선택한다.
   - 지도 위 체크포인트로 현재 세트와 남은 세트를 보여주고 마지막 세트에 성공 연출을 재생한다.
3. **지난 모험 다시 시작**
   - 첫 화면에서 최근 목표·시간·지역을 한 번의 탭으로 재시작한다.
   - 미완료 목표는 `이어가기`, 완료 목표는 `다시 도전`으로 구분한다.
4. **종료 알림과 미니 타이머**
   - 앱이 열려 있을 때는 운영체제 알림과 소리로 종료를 알린다.
   - 지원 브라우저에서는 작은 항상 위 타이머를 제공하고, 미지원 환경은 일반 타이머로 유지한다.

### P1 — 재방문과 차별화

5. **Recovery Quest** — 중단 세션을 실패로 표시하지 않고 5·10분 복귀 퀘스트로 축소한다.
6. **모험 월드 성장** — 완주 횟수에 따라 깃발, 산호 유적의 빛, 호수의 생물처럼 기존 장면이 조금씩 복원된다.
7. **Companion Memory** — 동료가 최근 목표, 자주 고른 시간, 돌아온 기록을 짧게 기억하고 인사한다. 생성형 AI 없이 규칙 기반으로 시작한다.
8. **행동형 리포트** — 누적 시간보다 시간대별 완주율, 중단이 적은 세션 길이, 다음에 하기 좋은 목표를 보여준다.

### P2 — 검증 뒤 확장

9. **부드러운 일정 알림** — 사용자가 직접 정한 시간에만 오늘의 한 가지를 묻는다.
10. **Silent Camp** — 공개 랭킹 없이 친구와 같은 시간에 조용히 집중하고 완주 여부만 공유한다.
11. **AI Quest 추천** — 반복 사용자와 결제 의향이 확인된 뒤 유료 분석 한도와 함께 활성화한다.

### 이번 단계에서 하지 않을 것

- 범용 할 일 관리 앱 수준의 캘린더·협업 기능
- 공개 랭킹과 경쟁형 연속 기록
- 캐릭터 상점과 복잡한 재화 경제
- 브라우저별 품질이 불안정한 기능을 필수 경로로 사용
- 결제 구조 없이 무제한 AI 분석 제공

### 검증 기준

- 첫 방문 후 첫 집중 시작까지 중앙값 3분 이내
- 목표를 적고 시작한 집중의 완주율 65% 이상
- 완주 사용자의 24시간 내 다음 집중 시작률 30% 이상
- 가입 사용자의 7일 내 재방문율 25% 이상
- 사용자 30명 이상에서 주 3회 완주 사용자 비율 추적

## 단계별 진행

### 0단계 — 문제 검증

목표: 코드를 크게 늘리기 전에 `AI 학습 퀘스트`가 실제 시작 행동을 개선하는지 확인한다.

- 대학생 10~15명 인터뷰
- 실제 PDF 기반 수작업 퀘스트 생성
- 업로드·분석·수정·시작 프로토타입 테스트
- 회상형과 3문항 확인 방식 비교
- 개인 자료 업로드에 대한 신뢰·삭제 요구 조사

통과 기준:

- 제안 수용률 60% 이상
- 첫 퀘스트 시작 중앙값 5분 이내
- 첫 주 유효 퀘스트 3개 이상 완료자 40% 이상

### 1단계 — Quest Loop MVP

목표: 한 명의 사용자가 한 개 PDF를 올리고 첫 유효 퀘스트를 완료해 다음 행동을 받는다.

#### 1-1. 계정과 저장

상태: 공개 이메일 계정, Supabase 저장소, Cloudflare 운영 배포 완료

- 게스트 시작
- 이메일·비밀번호 로그인과 선택형 Google 로그인
- 게스트 기록을 계정으로 이전
- PC·모바일 동기화
- 계정과 업로드 자료 삭제

현재 구현 범위:

- 기존 로컬 집중 기록과 타이머 설정을 D1 클라우드 상태로 저장
- 첫 로그인에서 로컬·클라우드 기록 병합
- 버전 충돌 감지와 한 번의 자동 병합
- 진행 중 타이머의 시작·일시정지·재개·완료를 같은 계정의 다른 기기에 반영
- 10초 간격과 화면 복귀 시 다른 기기의 최신 상태 확인
- 두 기기에서 동시에 완료해도 완료 기록 중복 방지
- 원문 이메일 대신 단방향 식별값으로 사용자 행 구분
- 클라우드 기록만 삭제하고 기기 기록은 보존

현재 추가 구현:

- Supabase Auth 이메일 회원가입·로그인·로그아웃·비밀번호 재설정
- 선택형 Google OAuth 진입
- `auth.uid()` 기반 RLS 사용자 데이터 격리
- 공개 Cloudflare Worker 배포 구성
- 기존 Sites·D1 호환 경로 유지

후속 범위:

- 과목·퀘스트 데이터가 생기면 동일 계정 상태에 연결
- 서로 다른 두 계정과 동일 계정의 PC·모바일 사용자 시나리오 검증

완료 조건:

- 다른 기기에서 동일 설정·완료 기록·진행 중 세션 확인
- 로그아웃 후 재로그인해 기록 복구
- 삭제 요청 후 원본 파일과 파생 데이터가 정책대로 제거

#### 1-2. 과목과 퀘스트

- 과목 프로젝트 생성
- 시험일·목표·가용 시간 입력
- 수동 퀘스트 생성·수정·완료
- 기존 모험 타이머와 퀘스트 연결

완료 조건:

- `과목 → 퀘스트 → 집중 세션 → 완료 기록`이 하나의 데이터 흐름으로 연결

#### 1-3. PDF 분석

- PDF 한 개 업로드
- 파일 크기·형식 제한과 실패 안내
- 목차·핵심 개념·페이지 범위 추출
- 3~7개 퀘스트 제안
- 예상 시간과 추천 공부법 제안
- 집중·휴식 시간과 권장 세트 수 제안
- 안전·기본·도전 목표가 포함된 Quest Contract
- 도전 목표는 완료 확인 기준과 함께 평가
- 관련 페이지와 신뢰도 표시
- 저장 전 전체 수정

완료 조건:

- AI 제안이 자동 확정되지 않음
- 모든 퀘스트에 목표와 자료 범위가 있음
- 모든 시간 예상은 단일 숫자가 아닌 범위와 근거를 함께 표시
- 예상보다 오래 걸려도 실패로 낙인찍지 않고 다음 예상치를 보정
- 오류가 나도 수동 퀘스트로 계속 진행 가능

#### 1-4. Camp Log

- 완료 후 자유 회상 한 줄 또는 3문항 확인
- 자신감 1~5
- 틀리거나 자신감이 낮은 개념을 복습 후보로 표시
- 실제 세트 수와 학습 확인 결과를 함께 사용한 효율 피드백
- 쉬움·적당함·어려움의 한 번 탭 체감 평가
- 다음 퀘스트 한 개 추천

완료 조건:

- 유효 퀘스트 정의를 시스템에서 계산 가능
- 사용자가 확인 단계를 건너뛸 수 있지만 일반 완료와 구분

#### 1-5. 학습 경로

- 과목별 전체·완료·복습 필요 퀘스트
- 이번 주 유효 퀘스트
- 다음에 할 행동 한 개
- 실제 학습한 개념과 페이지 기록

완료 조건:

- 누적 시간보다 완료 개념과 다음 행동이 먼저 보임

### 2단계 — Retention

목표: 사용자가 4주 동안 자신의 공부 동료와 학습 경로로 돌아오게 한다.

- 자신감·오답 기반 복습 퀘스트
- 최소 3개 유효 퀘스트 이후 개인별 집중·휴식·세트 추천
- 놓친 계획을 줄여 다시 시작시키는 Recovery Quest
- 시험일까지 남은 경로와 과부하 경고
- 캐릭터가 지난 과목과 성취를 기억하는 Companion Memory
- 퀘스트 완료로 복원되는 월드와 수집 요소
- 사용자가 허용한 시간대의 부드러운 알림
- 분석·퀘스트 품질 피드백

통과 기준:

- 4주차 재방문율 목표치 달성
- 첫 주 대비 4주차 유효 퀘스트가 급감하지 않음
- 복귀 퀘스트를 받은 휴면 사용자의 재시작률 개선

### 3단계 — Revenue

목표: 학습 결과 개선에 대해 지불할 사용자를 찾는다.

- 무료 분석 한도 실험
- Plus 결제 의향 테스트
- 적응형 시험 원정과 장기 리포트
- 추가 모험 지역과 캐릭터 스토리
- AI 비용과 결제 전환을 함께 보는 단위 경제성 대시보드

결제 실험:

- 월 4,900원 / 5,900원 / 6,900원 가격 민감도 비교
- 기능 잠금 화면보다 결과 미리보기 후 업그레이드 제안
- 연간 결제는 월 결제의 반복 사용 가치를 확인한 뒤 도입

### 4단계 — Social

목표: 경쟁 스트레스 없이 함께 공부하는 이유를 만든다.

- Silent Party
- 소규모 비공개 Study Camp
- 친구의 온라인 상태 대신 `함께 집중 중` 정도만 표시
- 공유 자료의 권한과 저작권 정책
- 선택형 Mentor View

실시간 랭킹과 공개 피드는 사용자의 요구가 반복해서 확인될 때만 검토한다.
