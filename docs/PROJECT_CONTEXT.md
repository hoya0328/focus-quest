# Focus Quest 제품 기획

마지막 업데이트: 2026-07-26

## 1. 제품 한 문장

**공부 자료를 올리면 AI가 지금 시작할 수 있는 학습 퀘스트로 나누고, 픽셀 모험 동료와 집중한 뒤 짧은 회상으로 실제 학습까지 확인하는 서비스.**

Focus Quest는 단순히 시간을 재는 타이머가 아니다. 사용자가 겪는 `막막함 → 미루기 → 집중 이탈 → 무엇을 배웠는지 모름`을 다음 루프로 해결한다.

```text
자료 등록 → AI 퀘스트 설계 → 모험 집중 → 짧은 회상 → 다음 퀘스트 조정
```

## 2. 주 사용자

### 1차 사용자

- 강의 PDF, 전공 서적, 자격증 자료처럼 분량이 큰 자료를 공부하는 한국 대학생
- 공부해야 할 것은 알지만 어디서부터 얼마나 해야 할지 정하는 데 에너지를 많이 쓰는 사람
- 기존 타이머는 며칠 쓰다가 동기가 떨어지고, 경쟁형 공부 앱은 부담스럽게 느끼는 사람

### 확장 사용자

- 취업·자격증 시험을 준비하는 20대 학습자
- 혼자 공부하며 계획과 실행을 함께 관리하고 싶은 사람

고등학생은 보호자·학교·연령 관련 고려가 추가되므로 초기 핵심 사용자에서 제외한다.

## 3. 핵심 문제와 JTBD

> 시험이나 과제를 앞두고 자료가 너무 많아 막막할 때, 내가 지금 바로 끝낼 수 있는 단위로 공부를 나누고, 그 시간 동안 집중하며, 끝난 뒤 실제로 이해했는지 확인하고 싶다.

사용자 문제는 세 단계로 나뉜다.

1. **시작 문제:** 자료의 분량과 난도를 보고도 예상 시간과 첫 행동을 정하기 어렵다.
2. **지속 문제:** 타이머 숫자만으로는 집중을 유지할 정서적 이유가 부족하다.
3. **학습 문제:** 오래 앉아 있었어도 무엇을 이해하고 기억했는지 알기 어렵다.

## 4. 가치 제안

### 핵심 가치

- **막막한 자료를 실행 단위로:** PDF를 페이지 수가 아니라 학습 목표 단위의 퀘스트로 변환한다.
- **집중 시간을 모험으로:** 캐릭터가 사용자와 동시에 움직이고, 완료 순간에는 장면 안에서 결과를 보여준다.
- **시간이 아닌 학습 진척으로:** 세션 종료 후 짧은 회상 또는 확인 문제를 통해 완료한 개념을 남긴다.
- **다음 행동을 자동으로:** 수행 결과와 자신감을 바탕으로 다음 퀘스트의 길이와 순서를 조정한다.

### 포지셔닝

Focus Quest는 `귀여운 타이머`와 `AI 요약 도구` 사이에 위치한다.

```text
귀여운 집중 경험 + 자료 기반 계획 + 실행 + 학습 확인
```

경쟁 서비스가 각각 잘하는 기능을 모두 복제하지 않는다. **자료에서 실제 공부 행동까지 연결되는 하나의 루프**에 집중한다.

## 6. 제품 원칙

1. **시작까지 5분을 넘기지 않는다.** 분석 기능이 정교해도 공부를 늦추면 실패다.
2. **AI 결과는 제안이며 사용자가 수정할 수 있다.** 과목, 목표, 예상 시간, 퀘스트 분할을 직접 고칠 수 있어야 한다.
3. **근거 없는 분석을 숨기지 않는다.** 퀘스트에는 PDF의 관련 페이지·단원과 예상 근거를 표시한다.
4. **시간을 채운 것과 학습한 것을 구분한다.** 완료 기록에는 집중 시간과 학습 확인 결과를 함께 남긴다.
5. **죄책감보다 복귀를 설계한다.** 연속 기록이 끊겨도 실패로 몰지 않고 다음에 할 가장 작은 퀘스트를 제시한다.
6. **보상은 공부 흐름을 방해하지 않는다.** 광고나 과도한 상점 팝업을 세션 시작·완료 사이에 넣지 않는다.
7. **캐릭터는 장식이 아니라 동료다.** 진행, 실패, 회복, 완료가 장면과 캐릭터 행동으로 연결되어야 한다.

## 7. 핵심 사용자 여정

1. 사용자가 과목과 목표일을 입력하고 PDF 한 개를 올린다.
2. AI가 과목, 자료 구조, 난도, 예상 총시간을 분석한다.
3. AI가 3~7개의 퀘스트와 각 퀘스트의 목표·범위·추천 공부법·집중/휴식 시간을 제안한다.
4. 사용자가 제안을 수정하거나 그대로 등록한다.
5. 오늘 할 퀘스트를 선택하고 모험 캐릭터와 집중을 시작한다.
6. 완료 연출 후 60~90초짜리 회상 질문 또는 3문항 확인을 수행한다.
7. 결과와 자신감을 바탕으로 다음 퀘스트의 순서와 복습 시점을 제안받는다.
8. 대시보드에서 공부한 시간보다 `완료한 개념과 남은 경로`를 먼저 확인한다.

## 8. AI Quest 설계 규칙

AI는 단순히 “25분 공부하세요”라고 말하지 않는다. 각 퀘스트마다 사용자가 도전할 수 있는 **Quest Contract**를 만든다.

### Quest Contract 구성

| 항목 | 설명 |
| --- | --- |
| 퀘스트 목표 | 세션 종료 후 사용자가 할 수 있어야 하는 행동 |
| 자료 범위 | 관련 단원과 PDF 페이지 |
| 추천 공부법 | 읽기, 구조화, 문제 풀이, 암기, 회상 중 적합한 방식 |
| 권장 세트 | 집중·휴식 시간과 반복 횟수 |
| 예상 총시간 | 휴식을 포함한 범위형 예상치 |
| 기본 목표 | 무리하지 않고 달성해야 하는 기준 |
| 도전 목표 | 학습 품질을 지키면서 더 적은 세트에 끝내는 기준 |
| 완료 증거 | 한 줄 회상, 개념도, 문제 정답률 등 |
| 예상 근거 | 분량, 난도, 과제 유형, 사용자의 과거 속도 |

### 추천 시간 방식

고정된 25분·5분을 모든 공부에 적용하지 않는다. 초기에는 다음 휴리스틱을 제안하고, 사용 기록이 쌓이면 개인별로 보정한다.

| 학습 유형 | 초기 추천 예시 | 세션 목표 |
| --- | --- | --- |
| 처음 읽는 어려운 개념 | 집중 30~40분 / 휴식 7~10분 | 핵심 구조 이해와 질문 표시 |
| 문제 풀이 | 집중 40~50분 / 휴식 10분 | 일정 문제 수 풀이와 오답 분류 |
| 암기·복습 | 집중 20~25분 / 휴식 5분 | 능동 회상과 즉시 확인 |
| 강의 정리 | 집중 25~35분 / 휴식 5~7분 | 한 단원을 자신의 언어로 구조화 |

이 값은 “과학적으로 모두에게 최적”이라고 표현하지 않는다. 사용자가 첫 3개 퀘스트를 수행하는 동안 실제 집중 시간, 완료 범위, 확인 결과, 체감 난도를 학습해 개인 권장 시간을 만든다.

### 세 단계 목표

모든 퀘스트에는 한 가지 성공선만 두지 않고 세 단계 목표를 제공한다.

1. **안전 목표:** 오늘 컨디션이 낮아도 시작할 수 있는 최소 진척
2. **기본 목표:** AI가 예상한 권장 세트 안에서 완료
3. **도전 목표:** 학습 확인 기준을 통과하면서 한 세트 적게 완료

도전 목표는 속도만으로 달성할 수 없다. 예를 들어 3세트 예상 퀘스트를 2세트에 끝냈더라도 완료 확인 점수가 기준보다 낮으면 “빠른 완주”가 아니라 “복습 필요”로 기록한다.

### 효율 피드백 규칙

효율은 `실제 소요 세트 ÷ 예상 세트`만으로 평가하지 않는다.

```text
유효 학습 효율 = 목표 범위 완료 + 학습 확인 + 집중 유지 + 예상 대비 세트
```

- **최적 루트:** 기본 또는 도전 세트 안에 완료하고 학습 확인 기준도 통과
- **안정적 완주:** 예상 세트 안에 완료했지만 일부 복습이 필요
- **깊이 있는 탐험:** 예상보다 오래 걸렸지만 학습 확인 결과가 좋음
- **경로 재설계:** 예상보다 오래 걸리고 이해도도 낮아 다음 퀘스트를 더 작게 분할

예상보다 오래 걸린 사용자를 “비효율적”이라고 부르지 않는다. AI의 추정이 틀렸을 가능성을 함께 인정하고 다음 추천을 보정한다.

### 동기부여 문구 원칙

강한 목표는 주되 죄책감과 허위 확신을 만들지 않는다.

- 시작 전: `이 단원은 3세트 원정입니다. 2세트 안에 이해도 80%를 넘기면 오늘의 최적 루트를 달성해요.`
- 중간: `첫 구간 통과. 지금 속도라면 기본 목표 안에 정상에 도착할 수 있어요.`
- 도전 성공: `예상보다 한 세트 빠르게, 이해도까지 지켰어요. 오늘의 최적 루트 완주!`
- 기본 성공: `권장 3세트 안에 목표 범위를 끝냈어요. 계획대로 안정적으로 완주했습니다.`
- 예상 초과: `이 단원은 예상보다 난도가 높았어요. 실패가 아니라 다음 경로를 더 정확히 찾은 기록이에요.`
- 복습 필요: `속도는 충분했지만 핵심 개념 하나가 남았어요. 15분 회복 퀘스트로 완성할 수 있어요.`

### AI 예상치 보정

퀘스트 완료 후 사용자는 한 번만 답한다.

- 예상보다 쉬웠어요
- 적당했어요
- 예상보다 어려웠어요

시스템은 실제 세트 수, 일시 정지, 완료 범위, 확인 결과, 체감 난도를 함께 저장한다. 최소 3개의 유효 퀘스트 이후부터 “일반적인 추천”과 “나에게 맞춘 추천”을 구분해 표시한다.

### 예시

```text
[오늘의 원정]
운영체제 3장 42~61p: 프로세스 상태 전이를 설명할 수 있기

추천 방식
개념 읽기 → 상태 전이도 직접 그리기 → 빈 종이 회상

권장 루트
집중 35분 + 휴식 7분 × 3세트
예상 총시간 112~126분

안전 목표
2세트 동안 42~53p를 읽고 상태 5개를 구분하기

기본 목표
3세트 안에 61p까지 완료하고 상태 전이도를 도움 없이 그리기

도전 목표
2세트 안에 완료하고 확인 문제 5개 중 4개 이상 맞히기

완료 보상
정상 신호탑 점등 + 다음 지역 해금
```

## 9. MVP

### MVP가 검증할 가설

> AI가 자료를 작은 퀘스트로 바꾸고 기존 모험 타이머와 연결하면, 사용자는 일반 타이머보다 더 빨리 공부를 시작하고 한 주 동안 더 많은 유효 학습 세션을 완료한다.

### 반드시 포함

1. **계정과 클라우드 저장**
   - 게스트 체험 후 선택형 로그인으로 기록 보존
   - 1차 구현은 현재 Sites에서 비밀키 없이 사용할 수 있는 ChatGPT 계정 로그인을 사용
   - Google 또는 이메일 로그인은 외부 OAuth 운영 경로와 도메인이 확정된 뒤 검토
   - PC와 모바일에서 과목·퀘스트·세션 동기화
2. **과목 프로젝트**
   - 과목명, 목표, 시험·마감일, 주당 가능 시간
3. **PDF 한 개 분석**
   - 초기에는 PDF만 지원
   - 과목·목차·핵심 개념·분량 분석
   - 페이지 근거와 분석 신뢰도 표시
4. **AI 퀘스트 설계**
   - 3~7개 퀘스트
   - 목표, 페이지 범위, 추천 방법, 예상 시간, 집중/휴식 조합
   - 등록 전 전체 수정 가능
5. **모험 타이머 연결**
   - 현재 등산·수영·낚시 중 선택
   - 중단·복귀·완료 기록
6. **학습 완료 확인**
   - 자유 회상 한 줄 또는 3문항 확인
   - 자신감 1~5 기록
7. **학습 경로**
   - 완료, 복습 필요, 다음 퀘스트 표시
   - 주간 유효 퀘스트 수와 완료 개념 표시

### 명시적 비목표

- 모든 파일 형식과 동영상 분석
- 범용 AI 챗봇 또는 과제 정답 제공
- 네이티브 수준의 강제 앱 차단
- 실시간 랭킹과 공개 소셜 피드
- 학교 LMS 대체
- 복잡한 캘린더 자동 편성
- 캐릭터 상점과 유료 아이템 경제
- 여러 명이 동시에 접속하는 멀티플레이

## 10. 차별화 기능 후보

### P0: 핵심 루프

- **AI Quest Builder:** PDF를 학습 목표 단위로 분해
- **Quest Contract:** 추천 시간·휴식·세트 수와 안전/기본/도전 목표 제시
- **Quest Route:** 자료 전체를 모험 지도처럼 보여주고 다음 행동을 한 개만 강조
- **Camp Log:** 세션이 끝나면 60~90초 회상 또는 확인 문제
- **Adaptive Next Quest:** 자신감과 오답에 따라 복습 또는 다음 단원 제안

### P1: 재방문과 애착

- **Companion Memory:** 캐릭터가 사용자가 공부한 과목과 지난 성취를 기억하고 짧게 반응
- **World Restoration:** 누적 시간 대신 완료한 퀘스트와 복습 결과로 새로운 장소가 복원
- **Recovery Quest:** 계획을 놓친 날에는 더 쉬운 복귀 퀘스트 자동 제안
- **Exam Expedition:** 시험일까지 남은 경로와 과부하 위험을 시각화

### P2: 네트워크 효과

- **Silent Party:** 친구와 같은 시간에 각자 다른 퀘스트를 수행하고 현존감만 공유
- **Study Camp:** 같은 수업 자료를 기반으로 비공개 그룹 경로 공유
- **Mentor View:** 사용자가 허용한 경우에만 튜터·스터디장이 진척과 막힌 개념 확인

## 11. 성공 지표

### North Star

**주간 유효 학습 퀘스트 완료 수**

유효 퀘스트는 `15분 이상 집중 + 종료 회상/확인 완료`를 모두 만족한 세션이다. 단순 누적 시간은 핵심 지표로 사용하지 않는다.

### 핵심 보조 지표

- 가입 후 첫 PDF 등록부터 첫 퀘스트 시작까지 걸린 시간
- AI 제안 퀘스트의 승인·수정·폐기 비율
- AI 예상 세트와 실제 세트의 오차
- 추천 공부·휴식 시간 채택률
- 기본 목표와 도전 목표 선택·달성률
- 첫 24시간 내 첫 유효 퀘스트 완료율
- 사용자당 주간 유효 퀘스트 수
- 1주차와 4주차 재방문율
- 퀘스트 시작 대비 완료율
- 복습 제안 수행률

### 보호 지표

- PDF 분석 실패율과 페이지 근거 오류 신고율
- AI 퀘스트를 대폭 수정한 비율
- 도전 목표 사용자의 완료 확인 점수 하락 여부
- 예상 초과 후 퀘스트 포기율
- 유효 퀘스트 1개당 AI 비용
- 업로드 자료 삭제 요청 처리 시간
- 세션 중 이탈 및 강제 종료 비율

## 12. 사업 모델 가설

### 무료

- 현재 모험 타이머와 로컬 기록
- 수동 퀘스트
- 월 2~3회의 PDF 분석 체험
- 기본 캐릭터와 기본 배경

### Focus Quest Plus

- 더 많은 PDF 분석과 클라우드 동기화
- 적응형 복습과 시험 원정 계획
- 장기 학습 리포트
- 추가 모험 지역·캐릭터 스토리

초기 가격은 확정하지 않는다. 월 **4,900~6,900원** 범위를 가격 민감도 인터뷰와 결제 의향 테스트에 사용하고, AI 비용과 4주차 잔존율을 확인한 뒤 결정한다. 캐릭터만 유료로 파는 것보다 학습 결과가 좋아지는 기능에 과금 근거를 둔다.

## 13. 가정과 미결 사항

### 결정

- 1차 사용자는 한국 대학생이다.
- 핵심 차별점은 `자료 → 계획 → 집중 → 회상 → 다음 행동` 루프다.
- 캐릭터와 픽셀 모험은 제품의 정서적 핵심으로 유지한다.
- MVP는 PDF 한 형식과 개인 학습에 집중한다.
- North Star는 시간이 아니라 유효 학습 퀘스트 완료 수다.

### 가정

- 사용자는 PDF 분석을 위해 자료 업로드에 동의할 의향이 있다.
- 퀘스트 제안이 충분히 수정 가능하면 AI의 시간 추정을 참고할 것이다.
- 60~90초의 학습 확인은 완료 경험을 크게 해치지 않는다.
- 안전·기본·도전의 세 단계 목표가 단일 목표보다 시작과 재도전을 돕는다.
- 사용자는 최소 3개의 퀘스트 이후 개인화된 시간 추천을 더 신뢰할 것이다.
- 대학생에게 경쟁보다 동료감과 개인 진척이 더 넓게 수용될 수 있다.

### 미결

- 첫 유료 고객을 전공 시험 준비생과 자격증 준비생 중 어디서 먼저 찾을지
- PDF 보관 기간과 즉시 삭제 옵션의 기본값
- 회상형과 객관식 중 어떤 완료 확인이 유지율과 학습감에 더 좋은지
- 강한 도전 문구가 동기를 높이는지, 압박으로 작용하는지
- 도전 목표를 사용자가 직접 선택하게 할지 자동으로 노출할지
- 무료 분석 횟수와 Plus 가격
- 캐릭터 서사를 과목별로 바꿀지, 모든 과목에서 한 세계를 공유할지

## 14. 초기 검증 계획

1. 대학생 10~15명을 모집해 실제 강의 PDF 한 개를 받는다.
2. 개발 전 수작업으로 AI 퀘스트 제안 화면을 만들어 5명에게 사용성 테스트한다.
3. 첫 시작까지 걸린 시간, 수정한 항목, 불신한 분석을 관찰한다.
4. 동일한 퀘스트에 `기본 목표만 표시`와 `안전·기본·도전 목표 표시` 두 버전을 비교한다.
5. 예상 세트와 실제 세트의 차이, 완료 확인 결과, 체감 압박을 함께 측정한다.
6. 2주 동안 현재 타이머만 쓰는 주와 AI 퀘스트를 쓰는 주를 비교한다.
7. 다음 기준을 만족하면 MVP 개발을 계속한다.
   - 참여자의 60% 이상이 제안된 퀘스트 중 하나를 큰 수정 없이 시작
   - PDF 등록 후 첫 퀘스트 시작까지 중앙값 5분 이내
   - 참여자의 40% 이상이 첫 주에 유효 퀘스트 3개 이상 완료
   - 60% 이상이 다음 주에도 사용할 의향을 표현
