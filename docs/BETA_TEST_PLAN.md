# Focus Quest 실제 베타 테스트

## 현재 상태

자동 QA·가상 시나리오와 실제 사용자 테스트는 별개다. 이 문서는 실행 준비 자료이며, 실제 참가자를 모집하거나 테스트를 완료했다는 기록이 아니다.

대표 링크: https://focus-quest.hoya0328.workers.dev

## 참가자와 기간

- 대학생·자격증 준비생·재택 작업자 등 5~10명을 사용자가 직접 모집한다.
- 첫 사용 15~30분, 다음 날 재사용 여부 확인, 7일 뒤 짧은 인터뷰를 진행한다.
- 참가자에게 불편하면 언제든 중단해도 된다고 알린다. PDF 업로드·회원가입은 선택이다.
- 비밀번호·인증 메일 링크·개인 PDF·학습 목표 전문·채팅 본문은 수집하지 않는다.
- 모집과 연락은 사용자/PM, 기술 문제 재현과 수정은 개발 담당이 맡는다.

## 그대로 보낼 수 있는 안내

> 픽셀 모험과 함께 집중하는 타이머 Focus Quest를 시험 중이에요. 링크를 열고 설명 없이 오늘 할 일로 한 번 집중해 주세요. 가입과 자료 업로드는 필수가 아니에요. 막히는 화면과 다음 날 다시 쓰고 싶은지만 알려주시면 도움이 됩니다. 비밀번호나 공부 자료는 보내지 말아 주세요.

메시지는 자동 발송하지 않는다.

## 첫 사용 과업

1. 친구를 고르고 25분 바로 시작을 눌러 본다. 링크를 연 시점부터 시작까지 걸린 시간과 망설인 지점을 기록한다. 맞춤 시간이 필요한 사람은 시간·음악 설정도 사용해 본다.
2. 집중을 시작하고 일시 정지·재개를 한다.
3. 완료 후 회고를 선택하고 휴식으로 넘어간다.
4. 새로고침한 뒤 기록이 유지되는지 확인한다.
5. 원하는 사람만 로그인하고 다른 기기에서 같은 기록을 확인한다.
6. 두 사람이 동의하면 캠프에 참가해 닉네임·동료·채팅·동시 시작·재접속을 확인한다.

## 실기기 체크

| 기기 | 검증 내용 | 결과 |
| --- | --- | --- |
| iPhone Safari | 세로·가로, 홈 화면 추가, 오디오 시작/정지, 잠금 후 복귀 | 미실행 |
| 설치한 iOS PWA | 명시적 알림 허용, 앱이 닫힌 상태의 예약 알림, 클릭 후 복귀 | 미실행 |
| Android Chrome/PWA | 설치, 오디오, 잠금·백그라운드 후 시간 보정, 종료 알림 | 미실행 |
| PC + 휴대폰 | 같은 계정의 기록 복구, 다른 계정과의 격리 | 미실행 |
| 두 별도 기기 | 캠프 참가·동시 시작·채팅·재접속·퇴장 | 미실행 |
| 지원/미지원 브라우저 | 작은 타이머 제공 또는 안전한 대체 안내 | 미실행 |
| 오프라인 전환 | 새로고침 안내, 진행 중 타이머 복구, 재연결 후 저장 | 미실행 |

모바일 Chromium 뷰포트 자동 검사는 실제 iPhone Safari나 OS 알림 검증을 대체하지 않는다.

## 비식별 기록 양식

| 참가자 코드 | 기기·브라우저 | 시작 성공/소요시간 | 완주 | 막힌 화면 | 다음 날 재사용 | 7일 뒤 재사용 | 재사용 이유 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| U01 | 미입력 | 미실행 | 미실행 | 미입력 | 미확인 | 미확인 | 미입력 |

가상 인물을 실제 참가자로 적지 않는다. 사용자의 이름이나 이메일 대신 U01~U10만 쓴다. 화면 캡처에 계정·개인 목표·자료가 있으면 가리고 공유한다.

## 판정과 다음 행동

- 로그인·저장·타이머·계정 격리 실패가 하나라도 있으면 신규 모집을 멈추고 수정한다.
- 설명 없이 첫 집중을 시작하지 못하는 사람이 반복되면 첫 화면과 준비실부터 수정한다.
- 다시 쓰는 이유가 확인되지 않으면 캐릭터·결제·AI 기능을 늘리지 않고 첫 3회 경험을 개선한다.
- 표본이 5~10명인 탐색 결과를 전체 시장의 유지율·매출 예측으로 일반화하지 않는다.
