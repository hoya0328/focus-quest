# 공개 베타 릴리스 기준

이 문서는 실행 양식이지 검사 통과 증명이나 배포 승인이 아니다. 실제 후보 SHA·결과·사업자 버전·담당자 확인은 비공개 운영 기록으로 관리한다.

## 소스와 변경
- [ ] 변경 범위와 동작·데이터·권한 영향 확인
- [ ] unrelated 변경 보존, lockfile·hosting 식별자·환경 경계 확인
- [ ] 검증된 커밋과 GitHub·배포 소스 일치

## 품질과 보안
- [ ] `docs:check`와 문서 도구 회귀
- [ ] 위험에 맞춘 규칙·타입·린트·빌드·렌더·브라우저 검사
- [ ] 실제 빌드·현재 파일·Git 이력의 비밀값 검사
- [ ] 필요한 익명/소유자/타계정 RPC·Storage 경계와 양성 대조
- [ ] migration 호환성·최소 권한·지원 라이선스 검토

## 운영
- [ ] 개인정보·약관·수집/삭제·오류 안내 일치
- [ ] 최근 백업 검증·미처리 삭제·호환 롤백 후보 확인
- [ ] 비용·메일 전달·알림·오프라인·실기기 의존성 확인
- [ ] 배포 후 읽기 전용 HTTP·보안 헤더·대표 주소·스케줄 확인

로그인·저장·타이머·계정 격리 실패는 공개 확대를 막는다. 미실행 실기기·실사용자 검증은 통과로 표시하지 않는다. [품질 기준](engineering/QUALITY.md), [현재 제한](engineering/LIMITATIONS.md), [베타 테스트](BETA_TEST_PLAN.md)를 따른다.
