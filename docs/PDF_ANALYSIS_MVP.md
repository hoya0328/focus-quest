# Focus Quest — PDF 분석 MVP

업데이트: 2026-07-28

## 제공 흐름

1. 로그인한 사용자가 과목 안에서 PDF 한 개를 선택한다.
2. 브라우저가 형식, 15MB 크기, 120쪽 제한을 확인한다.
3. PDF 원본은 Supabase의 사용자 전용 비공개 저장소에 보관한다.
4. 브라우저에서 페이지별 텍스트를 추출한다.
5. 서버는 로그인 토큰을 확인하고 3~7개의 학습 퀘스트 초안을 만든다.
6. 사용자는 제목, 완료 기준, 페이지, 공부법, 시간, 세트와 세 단계 목표를 수정한다.
7. 선택한 제안만 실제 과목 퀘스트로 등록한다.
8. 등록한 퀘스트는 기존 모험 타이머와 완료 세트 기록을 그대로 사용한다.

## 분석 결과

- 자료 요약
- 반복 핵심 개념
- 페이지 기반 자료 구간
- 3~7개 순차 퀘스트
- 관련 페이지와 분할 근거
- 예상 시간 범위
- 집중·휴식 시간과 목표 세트
- 추천 공부법
- 안전·기본·도전 목표

## AI와 기본 분석

- `OPENAI_API_KEY`가 운영 환경에 있으면 Responses API의 구조화 출력으로 분석한다.
- 기본 모델은 비용과 품질의 균형을 위해 `gpt-5.6-terra`, 추론 강도는 `low`로 설정한다.
- API 요청은 `store: false`이며 PDF 원본이 아니라 제한된 페이지 텍스트만 보낸다.
- 키가 없거나 AI 연결이 실패하면 페이지 분량과 반복 개념 기반 기본 분석으로 즉시 전환한다.
- 기본 분석 결과도 전부 수정할 수 있어 사용 흐름이 중단되지 않는다.

## 데이터와 권한

- `study_materials`: PDF 메타데이터, 상태, 요약과 분석 JSON
- Supabase Storage `study-materials`: 비공개 PDF 원본
- `study_quests.material_id`: 원본 자료 연결
- `source_pages`, `study_method`, 예상 시간 범위, `quest_contract`: 등록 후에도 분석 근거 보존

테이블과 파일 정책 모두 `auth.uid()` 및 사용자 ID 경로를 확인한다. 다른 사용자의 PDF와
분석 결과를 읽거나 변경할 수 없다.

## 제한과 다음 단계

- 이미지로만 구성된 스캔 PDF의 OCR은 아직 지원하지 않는다.
- 암호화 PDF, 15MB 초과, 120쪽 초과 자료는 명확한 안내와 함께 거절한다.
- AI의 시간 추정은 확정값이 아니라 범위와 근거로 표시한다.
- 1-4 Camp Log에서 실제 소요 시간과 회상 결과를 받아 추천을 보정한다.

## 운영 적용

1. `supabase/migrations/202607280001_study_materials.sql` 실행
2. 선택적으로 공개 Worker와 Sites에 `OPENAI_API_KEY`를 비밀 값으로 등록
3. `OPENAI_MODEL=gpt-5.6-terra` 등록
4. 검증된 빌드를 배포
