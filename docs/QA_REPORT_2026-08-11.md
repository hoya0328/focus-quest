1. Next.js와 Cloudflare 빌드 도구를 현재 호환 버전으로 갱신해 운영 의존성 취약점 4건을 제거했다.
2. Node가 `cloudflare:workers` 모듈을 직접 불러오며 실패하던 렌더링 테스트를 실제 Wrangler 로컬 런타임을 사용하는 방식으로 변경했다.
3. 휴식 세션에 잘못 노출되던 집중용 작은 타이머(PiP) 버튼을 집중 세션에서만 표시하도록 제한했다.

## 사용자 확인이 필요한 항목

브라우저 자동 조작이 반복적으로 시간 초과되어 다음 항목은 실제 브라우저에서 수동 확인이 필요하다.

1. `1분 집중 / 1분 휴식 / 2세트` 원정의 중간 체크포인트와 마지막 성공 연출
2. 집중 중 종료 후 Recovery Quest 생성 및 5·10분 재시작
3. 최근 모험의 `이어가기`와 `다시 도전`
4. Chrome의 알림 권한, 세션 종료 알림, 작은 타이머
5. 모바일 너비의 홈·설정·집중·완료 화면과 전체 화면 복귀
6. 서로 다른 브라우저 또는 계정에서 동일 Silent Camp 코드의 접속 인원 반영
7. 네트워크 끊김 뒤 로컬 기록 보존과 재연결 시 계정 동기화
