# Focus Quest — 과목·수동 퀘스트 MVP

업데이트: 2026-07-26  
상태: 구현 및 집중 검증 완료, Supabase 마이그레이션 적용 필요

## 사용자 흐름

1. 공개 계정으로 로그인한다.
2. 과목명, 목표, 목표일, 주간 목표 시간을 입력해 과목을 만든다.
3. 과목 안에 할 일, 완료 기준, 모험, 집중·휴식 시간, 목표 세트를 입력해 퀘스트를 만든다.
4. 퀘스트를 수정하거나 삭제할 수 있다.
5. `집중 시작`을 누르면 선택한 모험과 시간이 기존 타이머에 적용된다.
6. 집중 세션을 마치면 해당 퀘스트의 완료 세트가 자동으로 1 증가한다.
7. 목표 세트를 모두 채우면 퀘스트가 완료된다.
8. 같은 계정으로 다른 기기에서 로그인하면 같은 과목과 퀘스트를 확인할 수 있다.

## 데이터 모델

- `study_subjects`: 과목명, 목표, 목표일, 주간 목표 시간
- `study_quests`: 과목별 퀘스트, 모험, 집중·휴식 시간, 목표·완료 세트, 상태
- `study_quest_focus_sessions`: 퀘스트에 연결된 완료 집중 세션

모든 행은 Supabase 사용자 ID를 소유자로 가지며 RLS로 본인 데이터만 조회·변경할 수 있다.
과목을 삭제하면 포함된 퀘스트와 세션 기록도 함께 삭제된다.

## 중복 완료 방지

완료 세션은 `session_id`를 기본 키로 저장한다. 같은 세션의 완료 이벤트가 여러 기기에서
동시에 전달되거나 재시도되어도 퀘스트 세트는 한 번만 증가한다.

## 범위

이번 MVP에 포함:

- 과목 생성·삭제
- 수동 퀘스트 생성·조회·수정·삭제
- 목표 세트 기반 자동 완료
- 기존 Phaser 모험 타이머 연결
- PC·모바일 반응형 화면
- 사용자별 클라우드 저장과 권한 격리

다음 단계:

- PDF 업로드와 자료 메타데이터
- AI 과목·자료 분석 및 퀘스트 제안
- 퀘스트 종료 회상(Camp Log)
- 개인별 추천 시간 보정

이 마이그레이션이 적용되지 않으면 기존 타이머는 동작하지만 과목·퀘스트 저장 화면에
데이터베이스 설정 안내가 표시된다.
