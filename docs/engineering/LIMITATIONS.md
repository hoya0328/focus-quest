# 인수 시 확인해야 할 제한과 외부 의존성

코드 구현과 실제 운영 검증을 구분하는 목록이다. 이 문서를 읽었다고 미확인 항목이 해소되지 않는다.

## 공개 전 확인

| 항목 | 미확인/제한 | 완료 판정과 담당 역할 |
| --- | --- | --- |
| 일반 이메일 | 프로젝트 외 이메일의 가입·인증·재설정 전달과 현재 custom SMTP 설정 미확인 | 운영/QA: 별도 이메일로 실제 수신·링크·재로그인. 인증을 끄는 우회 금지 |
| 실제 모바일 | iOS/Android 잠금·복귀·오디오·알림·설치·PiP 차이 | QA: 실기기 1회 전체 집중/휴식 + 두 기기 캠프 |
| 장애 복구 | 로컬 암호화 사본·DPAPI 키가 같은 PC/Windows 계정에 의존 | 운영: 승인된 외부 사본과 독립 키 복구 절차·격리 복원. 비용 동의 없이 R2 활성화 금지 |
| 정기 작업 | PC/Codex/CLI 인증이 꺼지거나 만료되면 로컬 백업·사본 삭제 지연 | 운영: 최근 성공·미처리 삭제 확인. Worker Cron 정상만으로 로컬 완료로 판단 금지 |
| 비용/남용 | PDF 3개 한도는 계정 전체 비용의 하드캡 아님 | 운영: 실제 플랜·사용량·메일 한도·예산 경고 확인, 결제/유료 AI 임의 활성화 금지 |
| 지원/법률 | 문의 메일 실제 수신/회신·수동 보관 정리, 전문 법률 검토 미완료 | 운영/개인정보 담당: 연락 경로·적법성·문의 기한 검토. 법률 인증 완료로 광고 금지 |

## 기술 부채·확장 경계

- **장기 성장 원장:** history 400개, companionGrowth 2,000개 상한. 현재 보유 기록을 기준으로 월드/유물을 계산한다. 무제한 누적 성장 보장 전 별도 서버 원장이 필요하다.
- **PDF:** OCR·수식/표의 의미 복원 없음. 글자 상한에 따라 자료 일부만 문제 후보가 된다. 일반 고아 업로드 탐지기는 없고 계정 삭제의 owner sweep·명시 삭제 대장 재처리가 있다.
- **퀴즈 품질:** 결정적 빈칸 문제이며 의미 기반 AI 평가가 아니다. 정답 문장은 범위 안, 오답 보기 용어는 자료 전체에서 올 수 있다. null/건너뛰기 경로를 유지한다.
- **캠프:** 임시 메시지/클라이언트 타이머다. 서버 서명된 이벤트·서버 강제 채팅 rate limit·강력한 악성 멤버 대응을 제공했다고 주장하지 않는다. 신고의 영구 채팅 증거 보관도 없다.
- **Push:** 출발 리마인더이며 모든 기기의 정확한 초 단위 종료 알림이 아니다. 현재 성공 다음 due는 24시간 간격이어서 DST/시간대 이동 정책 고도화가 필요할 수 있다.
- **백업:** 계정 비밀번호/토큰/MFA/OAuth와 DB 전체 물리 상태를 포함하지 않는다. PDF는 DB snapshot 이후 읽어 전 시스템 단일 시점 복사와 다르다. 암호화 검증은 실제 운영 복원 성공의 대체물이 아니다.
- **문의:** 비로그인 단방향 접수다. 사용자 답장·메일 알림·첨부는 제공하지 않는다. 운영자가 문의함을 직접 확인해야 한다. 접수 후 90일만 보관하고 학습 백업에 넣지 않아 문의의 독립 장애 복구를 보장하지 않는다. IP 일 단위 식별값과 전체 한도는 공유 네트워크에서 정상 접수를 제한할 수 있다.
- **측정:** 로그인 사용자 중심의 비식별 집계다. 전체 방문자 전환율·가입 코호트 D7·실제 유료 전환으로 일반화할 수 없다.
- **문서:** 날짜별 QA/인계는 역사 자료다. 실시간 배포 번호·키·개인 실행 이력을 공개 기술 명세에 계속 붙이지 않는다.

## 의도적으로 제공하지 않는 것

유료 AI 의미 분석·결제·네이티브 앱 차단·스토어 서명/심사·공개 순위/피드·LMS/범용 AI 챗봇은 이번 공개 베타 계약 밖이다. Google OAuth는 구현 경로가 있어도 제공자 설정과 검증을 끝낸 환경에서만 활성화한다.

실제 사용자 검증 과업과 실패 시 모집 중단 기준은 [BETA_TEST_PLAN](../BETA_TEST_PLAN.md)에 있다. 인증·기록 저장·타이머·계정 격리가 실패하면 신규 공개 확대보다 수정이 먼저다.
